## About me

I'm a data professional from Kenya with an interest in analytics, data engineering, database systems, APIs and data-driven applications.

Most of my work sits somewhere between analysis and engineering. I enjoy taking raw datasets, cleaning and structuring them, building repeatable workflows around them, and presenting the results in a way that is useful to someone making a decision.

I'm especially interested in public health data, geospatial analysis, PostgreSQL, Python-based data pipelines and backend systems.

Currently, I'm going deeper into data engineering, pipeline design, PostgreSQL, Django and production Python.

## Selected work

### Kenya TB Surveillance & Analysis

An end-to-end analysis of tuberculosis data in Kenya, combining disease notifications, population data and geographic information to examine burden, trends and county-level differences.

The project includes data acquisition, validation, cleaning, transformation, exploratory analysis and population-adjusted indicators.

**Stack:** `Python` `Pandas` `GeoPandas` `Matplotlib` `Public Health Data`

[View repository →](https://github.com/WayneNyariroh/kenya_tb_surveillance_analysis)

---

### KCCB-ACTS Supported Sites Mapper

An interactive mapping and analytics application that combines facility locations, treatment indicators and HIV testing data into one operational view.

The application provides a clustered geographic map alongside analytical views for comparing regional, county and service-delivery performance.

**Stack:** `Python` `Folium` `Streamlit` `Pandas` `Geospatial Analysis`

[View repository →](https://github.com/WayneNyariroh/wynlb.kccbs_sites_map)

---

### SQL Public Health Data Quality Engine

A large-scale relational database project designed around public health reporting and analytics.

It explores schema design, indexing, relationships, data quality, geospatial support with PostGIS, analytical SQL and API access through PostgreSQL-based tools.

**Stack:** `PostgreSQL` `SQL`

[View repository →](https://github.com/WayneNyariroh/sql-public-health-data-quality-engine)

---

### Kenya Public Health Data Pipelie: Kenya HIV Programme Analytics

A Python project exploring how a reliable data pipeline can be designed with failure handling, validation, retries, logging, checkpoints and reproducible processing.

The project is documented as a practical learning case study, with examples explaining what each part of the pipeline does and why it exists.

**Stack:** `Python` `ETL` `Logging` `Validation` `Pipeline Design`

[View repository →](https://github.com/WayneNyariroh/Kenya_HIV_Programme_Analytics_Pipeline)
